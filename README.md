## 🚀 Instant Deployment & Running

### Option 1: Zero-Install Instant Viewing (Recommended)
Simply double-click `index.html` in your file explorer to open the full portfolio in **Google Chrome**, **Microsoft Edge**, **Safari**, or **Brave**.

### Option 2: Deploy to GitHub Pages / Vercel
1. Upload the files to a GitHub repository.
2. Under Repository **Settings > Pages**, select the `main` branch.
3. Your site will be live on `https://yourusername.github.io/sakkeer-kalodi-portfolio/` in seconds!

### Option 3: Modern Node / Vite Development
```bash
npm install
npm run dev
```
